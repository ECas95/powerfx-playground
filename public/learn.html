How grading works
Formulas are checked against two distinct input datasets. Equivalent outputs pass; typing a single hard-coded answer should not.
For Trace exercises, the simulated event payload is checked too.
Power Platform caveat
These are local mock-data exercises, not Microsoft tenant execution. Delegation, connectors, permissions and real behavior-side effects are not verified.
